# Fractal Tree

A JavaScript project that generates fractal trees using the Canvas API and recursive functions.

## Features

- 🌳 Generates tree-like fractals using recursion
- 🎨 Interactive controls for customizing tree appearance
- 📏 Adjustable branch length, angle, and depth
- 💾 Download the generated tree as an image

## Tech Stack

- **JavaScript** (ES6+)
- **Canvas API**
